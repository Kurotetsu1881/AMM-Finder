Veri Dönüştürücü

Dosya olarak (çift tıklayarak) açılan AMM Finder, klasördeki .csv / .json dosyalarını doğrudan okuyamaz; .js dosyalarını okur. Bu sayfa dönüşümü tek adımda yapar. GitHub / web adresi üzerinden kullanırken bu sayfaya ihtiyacınız yoktur; yalnızca index.html'i bilgisayarda çift tıklayarak açıyorsanız gereklidir.

Dosyaları buraya sürükleyin
veya tıklayıp seçin: filo.csv, amm_….json

    İnen dosyaları index.html'in bulunduğu klasöre koyun (eskilerin üstüne yazın).
